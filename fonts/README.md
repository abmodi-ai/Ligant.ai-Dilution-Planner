# Self-hosted typefaces

Brand rule: zero third-party requests. Both faces are served from this
directory; nothing is fetched from a font CDN.

| Face | Use | Files | Licence |
|---|---|---|---|
| Inter 4.1 | Prose, labels, flag text, UI | Inter-Regular/Medium/SemiBold.woff2 | SIL OFL 1.1 (LICENSE-Inter.txt) |
| IBM Plex Mono 1.1.0 | Data values, units, parameters, vessel labels, reason codes | IBMPlexMono-Regular/Medium/SemiBold.woff2 | SIL OFL 1.1 (LICENSE-IBM-Plex-Mono.txt) |

Sources: github.com/rsms/inter (release 4.1), github.com/IBM/plex (ibm-plex-mono 1.1.0).
